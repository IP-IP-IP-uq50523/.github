<h2>一、可用地址和网段大小是两回事</h2>
<p>服务商说给你八个IP，通常指一个二十九位网段，总地址八个，实际可用五个左右。这一点不问清，交付时容易产生误会。</p>
<p>网段大小由前缀决定，前缀数字越小，地址越多。可用数要在总地址里减掉网络地址、广播地址和网关。</p>
<p>点对点线路更特殊，两个地址里只有一个能给你用，另一个在运营商侧。</p>

<h3>理论与实际</h3>
<p>表里是理论值，实际可用还要看运营商是否占用其中某个地址做网关或管理。申请时要问的是一句话：能配到我这边有几个。</p>
<h2>三、网关、广播与网络地址的占用</h2>
<p>网段的第一个地址是网络地址，最后一个通常是广播地址，这两个都不能配到设备上。</p>
<p>网关占一个。多数运营商把网关放在网段首位或末位，实际可配置数因此再减一。</p>
<p>还有保留地址。有的运营商会预留几个做管理与监控，交付单上若不写明，配到冲突地址时很难排查。</p>
<h2>四、多个IP怎么落到不同设备</h2>
<h3>三种做法</h3>
<p>方式一是在路由器上做一对一的地址映射，公网IP逐个转到内网设备，内网用私有地址，管理简单。</p>
<p>方式二是把公网地址直接配到设备网卡上，设备直接用公网出口，适合服务器，但要注意安全策略。</p>
<p>方式三是按源地址做策略路由，多台设备共享一个出口网段但各走各的地址，适合需要出口隔离的场景。</p>

<h2>五、IP数量和带宽没有绑定关系</h2>
<p>带宽是管道粗细，IP是门牌号数量，两者独立计价。一条百兆带宽可以只配一个IP，也可以配一整段。</p>
<p>但IP多了会带来广播和地址解析开销，二层网络里地址太密集时，建议划分子网或做隔离。</p>
<p>谈价格时把两者分开谈，比带宽加IP打包更容易看清哪一项在被加价。</p>
<p>还有一种常见误解，认为地址越多出口越分散。若这些地址属于同一网段、同一条线路，对外仍出自同一个机房，分散效果有限。</p>
<h2>六、什么时候该申请更大的网段</h2>
<p>当可用地址用掉七成，或者新增设备需要独立出口时，就该考虑扩容。等到地址耗尽再申请，往往要等下一个周期。</p>
<p>扩容有两种，一是在原网段旁边加一段，二是换成更大的连续网段。前者改动小，后者需要重新规划地址。</p>
<p>换网段意味着地址会变，绑定了地址的业务要提前评估。这一点在签约时就该问清，扩容是否会改变现有IP。</p>
<p>最后提醒一句，可用地址数要在合同里写死，而不是听口头承诺。写进合同的数字，才是后面扩容和验收的依据。</p>
<h2>常见问答</h2>
<h3>一条专线最多能给几个IP？</h3>
<p>答：取决于服务商分配的网段，从单个地址到整段都有。常见起步是二十九位网段的五个可用地址，扩容按段增加。</p>
<h3>八个IP为什么只能用五个？</h3>
<p>答：二十九位网段共八个地址，去掉网络地址、广播地址和网关，通常剩五个可配。</p>
<h3>多个IP需要多条线路吗？</h3>
<p>答：不需要，一段地址可以跑在同一条线路上，通过路由器或策略路由分配到不同设备。</p>
<h3>IP数量增加会变慢吗？</h3>
<p>答：地址本身不拖慢速度，但二层广播与地址解析开销会随规模上升，地址多时建议划分子网。</p>
